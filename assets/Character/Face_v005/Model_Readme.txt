얼굴 수정본 v005

Adventurer_Face_v005.blend를 Blender 5.2.3에서 엽니다.
작업 폴더의 Open_Blender_Face_v005.cmd는 2번 모니터 위치로 실행합니다.
파일은 얼굴을 확대한 재질 미리보기 상태로 저장했습니다.

이번 변경
- 눈 밑의 반달 모양 돌출을 만든 볼의 단차를 실제 메시에서 수정했습니다.
- 입술의 사각형 루프를 따라 입꼬리 틈을 줄이고 입술 볼륨을 유지했습니다.
- 피부를 따뜻한 색으로 조정하고 볼의 홍조, 입술의 광택을 분리했습니다.
- 얼굴·귀·목의 피부색을 맞췄습니다. 눈동자와 눈썹의 원화 특징은 유지했습니다.
- 몸체와 머리카락의 메시 좌표는 v004와 동일합니다. 이전 .blend도 보존했습니다.

수정할 오브젝트
Head_Sculpted_ReferenceUV: 얼굴, 귀, 목. 선택 후 Tab으로 메시를 편집합니다.
Eyes_ReferenceUV: 눈. 이번에는 눈의 형태와 투사 텍스처를 유지했습니다.
현재 파일을 직접 수정한 뒤에는 다른 이름으로 저장하면 생성본도 보존됩니다.

확인 자료
Face_Front.png / Face_ThreeQuarter.png / Face_Profile.png: 실제 Blender 렌더.
Face_Clay_ThreeQuarter.png: 얼굴 텍스처를 제외해 표면 형태를 확인한 렌더.
Before_v004_SameLighting.png: 같은 사선 카메라와 조명을 사용한 수정 전 이미지.
Validation.json: 저장 파일 재열기, 원본 보존, 몸·머리 좌표 유지, 텍스처 패킹 검사.
모든 사용 텍스처를 .blend 내부에 넣었습니다.

남은 범위
정적인 얼굴 외형을 정리한 버전입니다. 표정 리깅, 눈동자 회전, 입 안·치아 구현은 별도 작업입니다.
얼굴의 일부 색상은 원화 투사를 사용하므로 크게 확대하면 눈썹·입술 질감이 흐립니다.
머리카락과 의상은 이번 수정 범위가 아닙니다. 게임용 리토폴로지와 엔진 검증도 미실시입니다.
몸체의 기존 Tripo 생성물 사용 권리는 이전 버전의 안내를 따릅니다. 추가 생성·결제는 없습니다.

재현
scripts/finish_character_face_v005.py는 v004에서 v005를 만듭니다.
다시 실행하면 v005 생성 파일이 덮어써지므로 직접 편집한 파일에는 실행하지 마세요.
