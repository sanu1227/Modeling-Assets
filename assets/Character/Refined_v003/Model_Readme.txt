수정 내용
- 기존 의상과 몸체는 유지하고, 깨진 얼굴·헤어를 교체했습니다.
- 얼굴은 MakeHuman의 CC0 쿼드 메시를 바탕으로 턱 길이, 광대 폭, 코, 입선을 직접 수정했습니다.
- 얼굴 색은 승인된 정면 원화를 UV에 투사했습니다. 실제 3D 메시와 재질이며, 렌더 이미지를 합성한 결과가 아닙니다.
- 눈은 독립 메시입니다. 머리카락은 MakeHuman bob01의 CC0 메시와 알파 텍스처를 피팅하고 수정했습니다.
- 팔·손의 회색 얼룩, 부츠의 색과 재질, 의상의 과한 광택을 수정했습니다.

Blender에서 수정할 대상
1. Head_Sculpted_ReferenceUV: 얼굴 형태. Sculpt Mode 또는 Tab으로 편집합니다.
2. Eyes_ReferenceUV: 두 눈의 독립 메시입니다.
3. Hair_Bob01_Chestnut: 머리카락. Edit Mode의 비례 편집으로 가닥의 흐름을 조정할 수 있습니다.
4. Body_Clothing_Tripo_Refined: 몸체와 의상이 합쳐진 기존 메시입니다.
5. 02_Studio: 촬영용 카메라·조명·바닥입니다.

File > Save As로 별도 작업본을 만든 뒤 수정하는 것을 권장합니다.
텍스처는 .blend 내부에 패킹되어 있습니다. Material Preview 또는 Rendered 모드에서 확인합니다.
scripts/refine_character_v003.py를 다시 실행하면 이 폴더의 생성 파일이 다시 만들어집니다.

현재 한계
- 외형 개선 단계입니다. 리깅, 스키닝, 애니메이션, 게임용 리토폴로지·최적화는 아직 하지 않았습니다.
- 얼굴의 정면 투사 텍스처에는 원화의 조명·그림자가 포함되어 있습니다. 극단적인 측면이나 조명 변경에는 별도의 텍스처 작업이 필요합니다.
- 머리와 몸은 별도 메시입니다. 애니메이션용 목 연결과 변형 검수는 후속 작업입니다.
- 원화와 동일한 모델이라고 보장하지 않습니다. 얼굴 입체 형태와 헤어 실루엣은 실제 렌더를 보고 비교해야 합니다.
- 기존 Tripo 생성 몸체를 포함합니다. 상업적 게임 배포 전 생성 당시 Tripo 플랜의 사용 권리를 확인해야 합니다. 이번 작업에서 유료 결제나 추가 생성은 하지 않았습니다.

검증

Adventurer_Refined_*.png: 해당 Blender 모델을 실제 렌더링한 결과입니다.
