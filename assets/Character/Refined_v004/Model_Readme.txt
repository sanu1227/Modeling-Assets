캐릭터 외형 개선본 v004

Adventurer_Refined_v004.blend를 Blender 5.2.3에서 엽니다.
이전 Refined_v003 폴더와 .blend는 보존했습니다. Validation.json의 source_v003_unchanged로 확인할 수 있습니다.

변경 내용
- 단발의 끝선과 옆머리를 조형하고, 머리 다발 14개를 추가했습니다. 귀 위 다발을 따로 만들어 관자놀이를 보완했습니다.
- 오른쪽 귀 뒤로 머리를 넘기고 귀와 머리카락이 겹치던 부분을 정리했습니다.
- 얼굴의 눈·눈썹·코·입은 원화를 유지하면서 볼·이마의 불필요한 원화 음영을 줄였습니다.
- 얼굴과 목의 피부색·표면 음영을 조정하고 입선의 작은 틈을 줄였습니다.
- 원래 의상 색과 질감을 유지하며 어깨·팔의 색상 오류를 국소 보정했습니다.
- 조끼의 봉제선·가장자리, 목 부분 단추 3개와 옷깃의 둥근 가장자리를 실제 지오메트리로 추가했습니다.

수정할 오브젝트
- Head_Sculpted_ReferenceUV: 얼굴과 목
- Eyes_ReferenceUV: 눈
- Hair_Bob01_Chestnut: 머리카락 기본 형태
- Hair_v004_*: 새로 추가한 머리 다발
- Body_Clothing_Tripo_Refined: 기존 몸체와 의상
- Vest_*, Collar_*, Shirt_Brass_Button_*: 추가 의상 디테일

수정 전후 비교
Before_v003_SameLighting.png와 Adventurer_Refined_Face_ThreeQuarter.png는 같은 카메라·조명 조건입니다.
Adventurer_Refined_*.png는 수정한 3D 모델을 실제 Blender에서 렌더링한 이미지입니다.
이미지 재생성이나 인물 사진 합성으로 결과를 대체하지 않았습니다.
텍스처는 .blend 내부에 패킹했습니다.

현재 한계
원화의 가는 웨이브와 현재 머리카락의 큰 다발 형태는 아직 차이가 있습니다.
근접해서 보면 일부 헤어 이음새, 얼굴의 원화 투사 흔적, 목과 옷의 경계, 생성 모델의 뭉친 의상·손 디테일이 남아 있습니다.
리깅·스키닝·게임용 리토폴로지·엔진 검증은 이번 작업에 포함하지 않았습니다.
몸체에는 기존 Tripo 생성물이 포함되므로 상업적 배포 전 생성 당시 이용 권리를 확인해야 합니다.
이번 작업에서 추가 생성 크레딧이나 결제를 사용하지 않았습니다.
