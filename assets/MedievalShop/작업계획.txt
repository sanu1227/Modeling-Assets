중세 판타지 목조 상점 — MOSS & OAK
작성일: 2026-10-25

목표
Blender에서 수정 가능한 배경용 2층 약초 상점을 제작한다. 본체는 폭 6.4m,
깊이 5.2m이며 돌 기단, 돌출된 2층, 가파른 박공지붕으로 실루엣을 만든다.
암갈색 목재, 따뜻한 회벽, 청록색 기와, 올리브색 차양을 사용한다.
외관 중심이며 실내, 충돌 메시, 엔진별 LOD, 라이트맵 UV는 이번 범위에서 제외한다.

실제 제작 방식 참고
1. Giovanna Barcelos, Corners of Croatia 제작 과정, Think Tank Training Centre.
   https://www.tttc.ca/the-cortex/project%20breakdowns/80lv-interview-learn-how-to-make-a-realistic-modular-environment-in-unreal-engine-5
   아티스트가 설명한 레퍼런스, 그레이박스, 반복 가능한 부품 목록, 재질,
   모델링과 UV, 최종 조명 순서를 참고한다. 특정 건물 디자인은 복제하지 않는다.
2. Epic Games, Architectural Modeling Guidelines.
   https://dev.epicgames.com/documentation/fortnite/architectural-modeling-guidelines-in-unreal-editor-for-fortnite
   건물을 벽, 지붕, 바닥, 트림으로 분리하고 반복 부품을 재사용하는 원칙을 참고한다.
   UEFN 전용 치수와 버텍스 예산을 이 독립 Blender 모델의 요구사항으로 사용하지 않는다.
3. Lee Perry, Modular Level and Component Design, Game Developer 2002.
   https://docs.unrealengine.com/4.26/udk/Three/rsrc/Three/ModularLevelDesign/ModularLevelDesign.pdf
   큰 덩어리를 먼저 검증하고 구성 부품을 반복 조립하는 접근을 참고한다.
   오래된 자료이므로 당시 하드웨어 성능 수치는 적용하지 않는다.

제작 계획과 완료 기준
1. 블록아웃
   - 미터 단위 설정. 기단, 본체, 돌출 2층, 삼각 박공과 지붕을 배치한다.
   - 약 2.2m 문을 기준으로 비례를 확인하고 별도 블록아웃 파일로 보존한다.
2. 주요 구조
   - 돌 기단, 목재 기둥, 수평 보와 대각 버팀대, 박공지붕, 낮은 옆채를 만든다.
   - 같은 규격의 목재, 기와, 돌은 메시를 공유한다.
   - 베벨은 수정 가능한 모디파이어로 남겨 모서리에 빛이 맺히도록 한다.
3. 중간 크기 디테일
   - 아치 문, 분할 창문, 덧문, 차양, 굴뚝, 간판을 추가한다.
   - 창문은 배경 외관용이며 실내로 연결되는 개구부는 만들지 않는다.
4. 작은 디테일과 재질
   - 통, 상자, 약병, 화분, 진열대와 일부 철물을 배치한다.
   - 직접 생성한 타일형 이미지 재질을 UV로 배치한다. 재질 이미지는 원본에 패킹한다.
   - 표면용 반복 UV이므로 UV 중첩이 있다. 라이트맵 전용 UV와 구분한다.
5. 검수
   - 앞면과 뒷면을 실제 렌더링하고 실루엣, 기와 틈, 떠 있는 소품을 확인한다.
   - 메시 유효성, 유한 좌표, UV, 재질, 면적이 0인 면, 메시 경계와 노멀을 검사한다.
   - GLB를 새 장면에 다시 가져와 메시 수, 삼각형 수와 전체 크기를 비교한다.
6. 전달
   - MedievalShop_blockout.blend: 초기 덩어리 구성.
   - MedievalShop.blend: 컬렉션별로 분리된 편집용 원본.
   - MedievalShop.glb: 건물과 소품. 촬영용 바닥, 카메라와 조명은 제외.
   - preview_front.png, preview_back.png: 실제 Blender 렌더.
   - validation.json: 생성 결과와 재임포트 검사.
   - 사용안내.txt: 파일 사용법과 재질·엔진 사용 범위.

구현 방법
Blender에 포함된 Python API로 실제 메시, UV, 재질, 조명과 카메라를 만든다.
외부 AI 3D 생성 서비스나 유료 에셋은 사용하지 않는다. 작업 단계는 위 제작
순서를 따르되 클릭 반복은 스크립트로 수행한다. 기존 상자·캐릭터 파일은 수정하지 않는다.

실행 결과
2026-10-25 계획의 여섯 단계를 완료했다. 형상 검증에서 면적이 0인 면,
비매니폴드 모서리, 서로 맞지 않는 면 방향은 모두 0개였다.
편집용 원본의 메시 1,600개를 GLB에서는 여섯 그룹으로 묶었다.
원본과 재임포트 결과 모두 삼각형 167,792개이며, 전체 크기 차이는 약
0.000001m였다. 재질 이미지 13개를 내장했고 촬영용 바닥·조명·카메라는 제외했다.
앞면과 뒷면 렌더로 배치와 외관을 확인했다. 자세한 수치는 validation.json에 있다.
