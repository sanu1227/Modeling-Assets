AUREL CITY — 현대 도시 장면

열기
프로젝트 폴더의 Open_Blender_Aurel_City.cmd를 실행한다.
또는 Aurel_City.blend를 Blender 5.2.3 이상에서 연다.
숫자패드 0으로 저장된 조감도 구도를 보고, F12로 렌더한다.
창 유리와 반사는 Rendered 모드에서 확인한다.

도시 구성
20개 블록, 34동, 건물 디자인 8종.
외곽 도로 중심선 기준 460×368m, 도로 바닥을 포함한 크기 480×388m.
Aurel: 기존 브론즈 커튼월 오피스. 이전 편집 원본에서 가져왔다.
Vela: 상층부가 단계적으로 후퇴하는 흰색 프레임 고층 오피스.
Harbor: 타원 평면, 은색 수평 띠와 유리 외벽의 곡면 오피스.
Terra: 테라코타 외벽과 반복 발코니의 주거동.
Lumen: 세로 브론즈 핀과 석재 프레임을 사용한 호텔.
Civic: 수평 차양과 유리창을 강조한 중층 오피스.
Arcade: 상점 어닝과 쇼윈도를 갖춘 저층 상가.
Library: 목재 슬랫과 넓은 지붕을 사용한 공공 도서관.

20개 블록 사이에 도로·차선·횡단보도·보도·가로수·신호등을 연결했다.
중앙공원에는 잔디, 원형 수경시설, 벤치, 목재 파고라를 배치했다.
도서관 앞에는 광장과 수경시설을 배치했다.
차량과 보행자는 크기를 확인하는 정적인 소품이다.

파일
Aurel_City.blend: 편집 가능한 전체 도시, 재질, 조명, 카메라.
Aurel_Building_Kit.blend: 건물 8종을 담은 Append용 컬렉션 라이브러리.
Aurel_City.glb: 도시의 건물·도로·공원·수목·차량·보행자. 촬영용 바닥과 조명은 제외.
city_aerial.png: 도시 전체 조감도.
city_avenue.png: 중앙 대로의 거리 시점.
city_park.png: 중앙공원과 도서관 주변.
city_layout.png: 위에서 본 블록과 도로 배치.
city_manifest.json: 건물 이름, 종류, 블록, 좌표, 회전, 배율과 소품 수.
validation.json: 형상·배치 검사 및 GLB 재임포트 검증 결과.

컬렉션
01_Buildings_34: 건물과 각 건물의 이동용 Empty.
02_Streets_and_Sidewalks: 도로, 보도, 횡단보도, 차선과 포장 줄눈.
03_Parks_and_Street_Trees: 공원, 광장, 나무와 화분.
04_Street_Furniture: 벤치, 가로등, 신호등과 쓰레기통.
05_Vehicles_and_People: 정적 차량과 인물 소품.
90_Cameras_and_Lighting: 촬영용 조명, 카메라, 주변 바닥.

건물 이동과 복제
B01_...부터 B34_...까지의 Empty를 선택하면 건물 위치·회전·높이를 바꿀 수 있다.
같은 종류의 건물은 메시 데이터를 공유한다. Edit Mode에서 수정하면 같은 데이터의 복사본에도 적용된다.
한 건물만 독립적으로 바꾸려면 해당 하위 오브젝트들을 선택한 뒤
Object > Relations > Make Single User > Object & Data를 사용한다.
나무와 차량도 같은 방식으로 데이터를 공유한다.

건물 키트 사용
새 장면에서 File > Append를 선택한다.
Aurel_Building_Kit.blend > Collection으로 들어가 KIT_로 시작하는 원하는 건물을 선택한다.
키트의 건물들은 각각 원점에서 제작됐다. 여러 컬렉션을 동시에 불러오면 원점에서 겹치므로 옮겨 배치한다.
이 파일은 Append용 라이브러리이며, 완성 도시를 보려면 Aurel_City.blend를 연다.

다른 시점 보기
90_Cameras_and_Lighting에서 원하는 카메라를 선택하고 Ctrl+숫자패드 0으로 활성화한다.
Camera_01_City_Aerial: 조감도.
Camera_02_Central_Avenue: 중앙 대로.
Camera_03_Park_and_Library: 공원·도서관.
Camera_04_Layout: 평면 배치.

성능과 사용 범위
건물·나무·차량의 메시 공유로 데이터 중복을 줄였다.
원본의 고유 평가 메시 42개, 고유 삼각형 1,417,912개를 공유한다.
도시 전체 배치 기준 삼각형은 5,950,512개, 렌더 가능한 오브젝트는 402개다.
GLB도 고유 메시 42개를 유지하며 파일 크기는 123,335,756바이트다.
재임포트 후 삼각형 수가 일치했고 전체 경계 크기의 차이는 0m였다.
다만 도시 전체를 렌더할 때 배치된 모든 삼각형을 처리하므로 가벼운 저사양 게임 모델은 아니다.
신규 건물의 실내는 유리 뒤의 얕은 공간과 일부 가구 표현이다. 전체 실내 동선은 제작하지 않았다.
게임 엔진용 LOD·충돌·오클루전·주행·내비게이션 및 실제 FPS 측정은 포함하지 않는다.
GLB의 투명 유리는 KHR_materials_transmission을 지원하는 가져오기 도구와 셰이더가 필요하다.
Blender의 미세 Bump는 GLB 노멀 맵으로 별도 베이크하지 않았다.

재생성
scripts/build_aurel_city.py: 도시, 건물 키트, 네 가지 렌더 생성.
scripts/verify_aurel_city.py: 형상·배치 검사, GLB 내보내기와 재임포트, 검증 보고서 생성.
재실행하면 AurelCity 폴더의 생성 파일을 갱신하므로 직접 편집한 작업은 다른 이름으로 저장한다.
기존 ModernTower와 MedievalShop 파일은 수정하지 않는다.
