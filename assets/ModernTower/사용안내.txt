AUREL — 현대 오피스 빌딩
2026-10-25 / Blender 5.2.3

열기
프로젝트 루트의 Open_Blender_Aurel.cmd를 실행하면 낮 장면을 연다.
야간 장면은 Aurel_Night.blend를 연다.
숫자패드 0 또는 View > Cameras > Active Camera에서 저장된 전경 구도를 본다.
유리와 조명은 Rendered 모드 또는 F12 렌더로 확인한다.
Material Preview의 기본 환경 조명은 저장된 렌더와 다르게 보일 수 있다.

구성
높은 로비 1개 층과 업무층 15개 층으로 구성한 약 65m급 오피스 건물이다.
모델의 실제 최고 높이는 64.805m이며 전체는 미터 단위를 사용한다.
포디움은 약 32×26m, 메인 타워는 약 22.4×19.2m이다.
모서리를 깎은 평면, 후퇴한 상층부, 중간 정원, 석재 로비와 브론즈 프레임을 사용했다.
유리 뒤에는 층별 바닥·천장·코어·일부 책상과 의자가 있어 실제 공간 깊이가 보인다.
실내 동선 전체, 계단실과 엘리베이터 내부는 구현하지 않았다.

기존 작업 대비 추가한 디테일
- 28mm 두께의 창 유리 메시, 별도 창틀·수직 핀·불투명 층간 패널.
- 투과·굴절·반사가 있는 유리 4종, 브론즈 금속, 이미지 기반 석재/목재 재질.
- 유리 출입문, 손잡이, 캐노피 타이, 목재 천장 슬랫과 매입 조명.
- 로비 카운터·소파·테이블·브랜드 글자, 외부 주소 표지.
- 테라스 유리 난간, 다층 식재, 벤치, 포장 줄눈과 보도 턱.
- 옥상 루버, 응축기 팬 가드, 설비실과 코핑.
- 낮/야간 조명 장면과 입구 근접 렌더.

파일
Aurel_blockout.blend: 큰 덩어리의 초기 구성.
Aurel_Day.blend: 낮 조명과 카메라를 저장한 편집 원본.
Aurel_Night.blend: 야간 조명과 카메라를 저장한 편집 원본.
Aurel.glb: 건물과 부속 조경을 여섯 그룹으로 합친 재사용 파일.
hero_day.png / hero_night.png: 1600×1900 전경 렌더.
entrance_detail.png: 1700×1100 입구 근접 렌더.
Textures: 직접 생성한 이미지 재질. .blend와 GLB에도 필요한 이미지를 내장했다.
작업계획.txt: 설계 계획과 참고 자료.
validation.json: 메시 검사와 GLB 재임포트 결과.

컬렉션
01_Structure: 슬래브, 코어, 기단과 석재 구조.
02_Curtainwall: 유리, 스팬드럴, 창틀과 핀.
03_Interiors: 창을 통해 보이는 가구, 실내 표면과 발광 스트립.
04_Architectural_Details: 문, 캐노피, 난간과 표지.
05_Landscape: 식재, 화분과 벤치.
06_Rooftop: 설비실과 옥상 장치.
90_Presentation: 촬영용 도로·주변 바닥·반사용 주변 건물·카메라·조명.

편집과 배치
AUREL_ROOT를 이동·회전하면 건물과 부속 조경을 함께 옮긴다.
다른 Blender 장면에서는 01~06 컬렉션을 Append하고 90_Presentation을 제외한다.
반복 부품은 메시 데이터를 공유하므로 Edit Mode 수정이 복사본에 함께 적용될 수 있다.
한 부품만 수정하려면 Object > Relations > Make Single User에서 Object & Data를 선택한다.
화분과 가구는 컬렉션별로 분리되어 있으므로 배경 환경에 맞게 일부를 빼거나 옮길 수 있다.

검증 결과
원본 메시 오브젝트 6,675개, 고유 평가 메시 조합 180개.
베벨 적용 후 건물과 부속 조경의 삼각형 475,900개, 재질 20개.
GLB는 메시 6개이며 삼각형 수와 전체 크기를 재임포트해 비교했다.
GLB에는 이미지 5개와 유리 Transmission 재질 4개가 포함된다.
검사된 메시에서 퇴화 면, 열린 모서리, 면 방향 불일치가 발견되지 않았다.
개별 닫힌 부품을 조립한 모델이며 건물 전체가 단일 수밀 메시라는 의미는 아니다.

사용 범위
이 파일은 근거리 외관과 렌더 품질을 우선한 고상세 모델이다.
유리 투과, 내부 가구, 개별 잎 때문에 기존 최적화 목조 상점보다 렌더 비용이 높다.
게임에서 건물을 대량 배치하려면 사용 엔진과 카메라 거리에 맞춘 별도 LOD,
실내 생략, 식재 단순화, 충돌과 재질 조정이 필요하다. 이 건물의 해당 엔진 작업은 미실시다.
GLB의 유리 표현은 KHR_materials_transmission을 지원하는 가져오기 도구/셰이더가 필요하다.
Blender 재질의 미세 Bump는 GLB 노멀 맵으로 베이크하지 않았다.
GLB에는 촬영용 조명과 도로가 들어 있지 않으므로 엔진에서 환경과 조명을 다시 설정한다.
건축법, 구조 안전성, 방수·열 성능을 검증한 실제 건축 설계 도면은 아니다.

재생성
scripts/build_aurel.py: 별도 ModernTower 폴더의 모델과 렌더를 생성한다.
scripts/polish_aurel_views.py: 저장된 장면의 촬영 설정만 갱신하고 다시 렌더한다.
scripts/verify_aurel.py: 원본과 GLB를 검사한다.
재실행 시 생성 파일을 다시 쓰므로 직접 편집한 결과는 다른 이름으로 저장한다.
기존 MedievalShop 파일과 최적화 파일은 이 스크립트가 수정하지 않는다.
